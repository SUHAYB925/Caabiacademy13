      About This Course

      Bilow safarkaaga Web Development

      Beginner

      Koorsadan HTML5 waxay kuu furaysaa albaabka dunida Web Development. Waxaad ka bilaabaysaa eber, adigoo baranaya sida bogagga web-ku u dhismaan iyo sida HTML5 loogu abuuro qaab-dhismeed nadiif ah.

      Waxaad si tallaabo-tallaabo ah u baran doontaa headings, paragraphs, links, images, lists, tables iyo forms. Waxa kale oo aad fahmi doontaa Semantic HTML, accessibility iyo aasaaska SEO, adigoo adeegsanaya tusaalooyin iyo layliyo wax ku ool ah.

      Casharradu waxay ku bari doonaan sida loo geliyo sawirro, audio iyo video, loona dhiso bogag si fiican loo habeeyey. Marka aad dhammayso, waxaad diyaar u noqon doontaa inaad u gudubto CSS iyo JavaScript, kadibna aad barato React iyo Next.js.

      Waxaad u baahan tahayComputer · Browser · Visual Studio Code
